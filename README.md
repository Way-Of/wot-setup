## Installation

### Windows
1. Download `WayOfTeams-Setup.exe`
2. Run the installer
3. Follow the 6-step wizard
4. Launch WayOfTeams from your desktop

### macOS
1. Download `WayOfTeams.dmg`
2. Open the disk image
3. Drag WayOfTeams to Applications
4. Launch from Applications or Spotlight

### Linux
1. Download `WayOfTeams.AppImage`
2. Make it executable: `chmod +x WayOfTeams.AppImage`
3. Run: `./WayOfTeams.AppImage`

## What's Included

- **Phoenix/LiveView UI** — Real-time dashboard, tickets, kanban, standups
- **Local AI Support** — Works with LM Studio and Ollama (your models, your machine)
- **Anchor Memory** — Persistent knowledge base and semantic search
- **OpenChamber** — Browser-based AI coding workspace
- **MCP Server** — 223+ tools for OpenCode, Claude Code, Codex, and more

## First Launch

On first launch, WayOfTeams will:

1. Detect available AI models (LM Studio, Ollama)
2. Ask if you want to connect to a team (optional — works fully offline)
3. Guide you through initial setup

## Offline Mode

WayOfTeams works fully offline. All data stays on your computer unless you explicitly enable cloud sync.

## Updates

WayOfTeams checks for updates automatically. You can also check manually from Settings → Check for Updates.
